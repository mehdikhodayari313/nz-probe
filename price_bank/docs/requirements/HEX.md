# HEX – مبدل‌های حرارتی (وضعیت: در حال بررسی)

## شاخص تعدیل (پیش‌فرض، وزن‌ها قابل تغییر در بانک)
| زیررده | سبد پیش‌فرض |
|---|---|
| HEX-PLT صفحه‌ای، HEX-SPL اسپیرال، HEX-CHL چیلر، HEX-LMP یکجا | 100% C28.25 |
| HEX-STE پوسته و لوله | 70% C28.25 + 15% C24.10 + 15% C24.20 |
| HEX-ACH ایرکولر | 85% C28.25 + 15% C24.42 |
| HEX-CIP شست‌وشوی درجا | 100% C28.13 |

- C24.10 ≡ گروه C24.1 و C24.20 ≡ گروه C24.2 (هر گروه NACE فقط همین یک کلاس را دارد) → سری رسمی EA20 یوروستات، بدون جایگزین.
- C25.30 ≡ گروه C25.3: EA20 فقط 2018–2025؛ 2000–2017 با زنجیره‌ی رشد آلمان (C25.3 DE) بازسازی شده (⚠ علامت‌دار). فعلاً در سبد مبدل استفاده نمی‌شود (برای هیترها).
- سری‌های BLS آمریکا (331110، 331210، 332410-1) فقط جایگزین/کنترل‌اند: ۲۰ تا ۴۰٪ تعدیل بیشتر از یوروستات می‌دهند (دلاری).
- داده: `docs/data/PPI_all_series_14050723.csv`؛ خام: `tool/data/eurostat_ppi_20261015c.json`، `tool/data/bls_ppi_20261015.json`.
