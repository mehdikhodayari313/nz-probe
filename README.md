## نصب
1. فایل zip را دانلود کنید (دکمه‌ی «Download» یا «View raw»).
2. در یک پوشه Extract کنید و `price_bank.exe` را اجرا کنید. نصب یا دسترسی Administrator لازم نیست.
3. برای به‌روزرسانی، نسخه‌ی جدید را در همان پوشه Extract کنید؛ داده‌ها (در پوشه‌ی داده‌ی کاربر) سر جایشان می‌مانند.
